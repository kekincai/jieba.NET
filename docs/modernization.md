- Segmenter、Analyser、CLI、测试均面向 `net10.0`，与 VideoCleaner 保持一致；global.json 允许 .NET 10 SDK feature band 前滚。
- 移除 Newtonsoft.Json、System.Configuration.ConfigurationManager、CommandLineParser，核心/分析库/CLI 没有第三方运行时 PackageReference。
- 默认词典、IDF、普通 HMM 与 POS 模型内嵌。显式外部目录在首次资源读取前设置，模型深度受限、字符键严格校验，错误资源明确失败。
- 修复 HMM/DAG 平局选择、全模式边界、UTF-16 代理对、POS 回退/正则、TextRank 文化相关排序及删词后 HMM 重新合词。

- 读写锁保护同一词典的完整分词操作。默认共享词典保留兼容性；显式独立词典隔离主词典、用户词、标签、删除词与加载记录。HMM/POS 模型共享，独立词典有额外 Trie 内存成本。
- HMM 与 POS 模型按需加载；TF-IDF 在未限制词性时不创建 POS 分词器。DAG/路径计算使用 .NET 10 Span 字典查找，减少临时字符串；正则使用源生成。
- 命令行不再等待回车，逐行读写，修正 --no-hmm 参数方向，提供 stderr 和非零错误码。
- IDF 解析使用 invariant culture，并在替换前校验；IDF/停用词更新失败保留原先有效状态。

## N100 性能

最终数据和方法见下方性能表；原始逐进程测量保存到 `docs/performance/n100.json`。这不是 Python/C# 性能对比：旧版 C# 与改造版使用同一 C# 测量程序、同一组输入，在同一 .NET 10 运行时上顺序执行。基线代码没有业务修改，仅将项目的编译目标限制为原有 netstandard2.0 分支以便构建。

基线包含历史漏洞依赖，仅在忽略的 `artifacts/perf-baseline` 中用于对照，不在交付包、项目引用或 CI 依赖内。交付代码的依赖审计不包含该历史对照副本。


测量环境：Intel N100，4 核 4 线程，Windows x64，.NET 10.0.13。每个进程先测首次调用，再预热 50,000 次并等待 1 秒让分层 JIT 稳定，然后测 5 轮、每轮 100,000 次。每种模式每个实现启动 3 个独立进程、交替运行次序，下表取进程结果的中位数。所有前后对照的结果 checksum 相同。

| 模式 | 原版 次/秒 | 改造后 次/秒 | 吞吐变化 | 每次分配 B：原版 → 改造后 |
|---|---:|---:|---:|---:|
| 精确 HMM 开 | 84,567 | 125,551 | +48.5% | 8,816 → 6,029 |
| 精确 HMM 关 | 105,201 | 152,984 | +45.4% | 7,360 → 4,566 |
| 搜索模式 | 83,009 | 90,714 | +9.3% | 9,570 → 6,783 |
| TF-IDF（不限制词性） | 70,132 | 79,729 | +13.7% | 10,124 → 7,337 |

| 模式 | 首次调用 ms：原版 → 改造后 | 初始化后托管内存 MiB：原版 → 改造后 | 每 10 万次进程 CPU ms：原版 → 改造后 |
|---|---:|---:|---:|
| 精确 HMM 开 | 1,329 → 973 | 34.75 → 34.59 | 1,172 → 797 |
| 精确 HMM 关 | 1,223 → 671 | 34.74 → 33.40 | 969 → 641 |
| 搜索模式 | 1,347 → 801 | 34.74 → 34.59 | 1,188 → 1,078 |
| TF-IDF（不限制词性） | 3,433 → 1,132 | 96.54 → 51.47 | 1,406 → 1,234 |

这里的“首次调用”不含进程启动时间，文件系统缓存可能已经预热；托管内存是首次调用后强制 GC 的快照，不是峰值或整个应用的内存。TF-IDF 的内存下降主要来自未使用词性过滤时不加载 POS 数据；启用词性过滤后仍需对应数据。原始文件也保留了工作集字段。

这些数字来自固定 16 个文件名的内存内重复调用，不包括磁盘扫描、SQLite 写入、VideoCleaner 过滤/统计和大量不同文件名的缓存行为，因此不能当作完整媒体库扫描速度。普通 Cut 采用一个调用线程；运行时的 JIT/GC 仍可能使用后台线程。

复测现代版：`./scripts/benchmark.ps1 -Operations 100000`。对照旧版时额外传入同一测量程序构建的 `-BaselineDll`；原版有历史漏洞依赖，不用于生产引用。
